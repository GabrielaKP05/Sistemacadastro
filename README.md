# Sistema de Cadastro

Este é um projeto de um **Sistema de Cadastro** desenvolvido em Python. O objetivo deste sistema é realizar o cadastro de pessoas, armazenando suas informações como nome, CPF e idade. O sistema permite adicionar novos cadastros, listar todos os cadastros registrados e buscar por cadastros específicos.

## Funcionalidades

- **Cadastrar pessoa:** Permite adicionar uma nova pessoa ao sistema, registrando nome, CPF e idade.


## Estrutura do projeto

- **`cadastro.py`**: O script principal que contém toda a lógica do sistema de cadastro.
